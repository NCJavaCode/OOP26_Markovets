# Система обліку домашніх тварин

## Про проєкт

Програма для зберігання та керування інформацією про домашніх тварин.

## Мета проєкту 

Навчитися створювати об'єктивно-орієнтовані програми мовою Java та використовувати принципи ООП.

## Основні класи 

- Pet - домашня тварина.
- Owner - власник тварини.
- Clinic - ветеринарна клініка.

## Можливості програми

- створення інформації про тварину;
- перегляд даних;
- зміна даних;
- перевірка правильності введених даних.
